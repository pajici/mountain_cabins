# mountain_cabins

This is a full-stack web application for **booking mountain cabins**, built with **Angular** for the frontend and **Java with Spring** for the backend. The application provides an intuitive and seamless experience for users to browse, book, and manage cabin reservations.

## Features

The application supports **three types of users**:

1. **Customer** – Can browse available cabins and make reservations.
2. **Owner** – Manages their cabins, reviews reservations, and updates availability.
3. **Admin** – Oversees the entire system, manages users, and ensures smooth operations.

Additional features include:  

- Easy-to-use and responsive user interface  
- Reservation management and calendar view  
- User authentication and role-based access control  
- Cabin management for owners (add, edit, delete)  
- Admin dashboard for monitoring and reporting  

## Technologies Used

- **Frontend:** Angular, HTML, CSS, TypeScript  
- **Backend:** Java, Spring Boot, Spring Security  
- **Database:** MySQL
